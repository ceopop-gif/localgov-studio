# Skill: Local Government Website Builder TH

## Purpose
ใช้สำหรับวิเคราะห์ วางโครงสร้าง ออกแบบ สร้าง และตรวจสอบเว็บไซต์ของหน่วยงานปกครองส่วนท้องถิ่นในประเทศไทย เช่น อบต. เทศบาลตำบล เทศบาลเมือง และเทศบาลนคร โดยเน้นให้เว็บไซต์เป็นทั้งศูนย์ข้อมูลราชการ ศูนย์บริการประชาชน E-Service ระบบข่าวสาร ระบบความโปร่งใส และระบบหลังบ้านสำหรับเจ้าหน้าที่

---

## 1. หลักการสำคัญ

เว็บไซต์ต้องออกแบบโดยยึดประชาชนเป็นศูนย์กลาง ไม่ใช่โครงสร้างราชการเป็นศูนย์กลาง ผู้ใช้ควรเข้ามาแล้วรู้ทันทีว่า “ต้องการทำอะไร” และกดไปยังบริการได้ง่าย

ต้องรองรับ:
- Mobile First
- Tablet
- Desktop
- ภาษาไทยเป็นหลัก
- ตัวอักษรอ่านง่าย
- ปุ่มขนาดใหญ่
- ผู้สูงอายุและผู้พิการ
- Responsive Design
- SEO
- Social Sharing
- Search
- Accessibility
- PDPA
- Security

## 17. AI สำหรับเจ้าหน้าที่

### AI เขียนข่าว
เจ้าหน้าที่กรอกข้อมูลพื้นฐาน:
- กิจกรรมอะไร
- ใครเป็นประธาน
- จัดที่ไหน
- วันที่
- วัตถุประสงค์
- ผลการดำเนินงาน

AI สร้าง:
- หัวข้อข่าว
- คำโปรย
- ข่าวฉบับเต็ม
- Caption Facebook
- Hashtag
- SEO Title
- SEO Description

### AI สรุปเอกสาร
รองรับ PDF / Word / ประกาศ / รายงาน / แผนงาน และสรุปเป็นภาษาที่ประชาชนเข้าใจง่าย

### AI Search / Chatbot
ตัวอย่างคำถาม:
- ขอถังขยะต้องใช้เอกสารอะไร
- แจ้งไฟถนนเสียตรงไหน
- ผู้สูงอายุสมัครเบี้ยยังชีพอย่างไร

AI ต้องค้นจากข้อมูลจริงของเว็บไซต์ก่อนตอบ

## 29. ข้อมูลที่ต้องรวบรวมก่อนเริ่มสร้างเว็บไซต์

### Required
1. ชื่อหน่วยงาน
2. จังหวัด
3. Logo
4. ที่อยู่
5. เบอร์โทร
6. ผู้บริหารปัจจุบัน
7. วิสัยทัศน์
8. โครงสร้างหน่วยงาน
9. บริการหลัก
10. ข่าวล่าสุด

### Optional
- สีประจำหน่วยงาน
- รูปสถานที่
- รูปผู้บริหาร
- Facebook
- LINE OA
- YouTube
- แผนที่
- โครงการเด่น
- OTOP
- สถานที่ท่องเที่ยว

หากมีเว็บไซต์เดิม ให้ตรวจเว็บไซต์เดิมและนำเฉพาะข้อมูลที่ยังเป็นปัจจุบันมาใช้

**ห้ามแต่งชื่อผู้บริหาร เบอร์โทร ที่อยู่ งบประมาณ ข่าว โครงการ หรือข้อมูลราชการขึ้นเอง**

## 30. Workflow เมื่อได้รับคำสั่ง “สร้างเว็บ อบต./เทศบาล”

1. รวบรวมข้อมูลจริงของหน่วยงาน
2. ตรวจสอบความถูกต้องและความใหม่ของข้อมูล
3. จัดหมวดข้อมูล
4. สร้าง Information Architecture
5. ออกแบบหน้าแรก
6. ออกแบบหน้าบริการประชาชน
7. ออกแบบ E-Service
8. ออกแบบระบบข่าว
9. ออกแบบ ITA / OIT
10. ออกแบบระบบหลังบ้าน
11. ออกแบบ Workflow เจ้าหน้าที่
12. ตรวจ Mobile / Tablet / Desktop
13. ตรวจ SEO
14. ตรวจ Accessibility
15. ตรวจ Security และ PDPA

## 31. กฎการใช้ข้อมูล

ให้ใช้ข้อมูลจากแหล่งเชื่อถือได้ เช่น:
1. เว็บไซต์ทางการของหน่วยงาน
2. เว็บไซต์กรมส่งเสริมการปกครองท้องถิ่น
3. เว็บไซต์จังหวัด
4. เว็บไซต์หน่วยงานราชการ
5. เอกสารราชการ
6. ข้อมูลที่ผู้ใช้ให้

ข้อมูลที่มีโอกาสเปลี่ยน เช่น ผู้บริหาร เบอร์โทร ข่าว งบประมาณ โครงการ และ ITA ต้องตรวจสอบข้อมูลล่าสุดก่อนใช้งาน

หากข้อมูลไม่ชัดเจน ให้ระบุว่า “ต้องตรวจสอบ” แทนการเดา
